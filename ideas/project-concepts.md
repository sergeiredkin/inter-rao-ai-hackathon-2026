# Project Concepts

## Concept 1 (Primary)

# AI Process Engineer for Energy Operations

## Problem

Large energy companies operate with complex procedures, regulations, and operational instructions. Converting these documents into executable and understandable process models requires significant expert effort.

## Solution

An AI assistant that transforms natural language process descriptions into validated BPMN 2.0 diagrams.

## MVP

Input:
- Text description of an operational process
- Procedure document
- Work instruction

Output:
- BPMN 2.0 diagram
- Process steps
- Roles and responsibilities
- Validation warnings
- Improvement suggestions

## Future extensions

- Process mining
- Automation opportunity detection
- Integration with enterprise systems
- Knowledge base connection

## Concept 2

# Energy IT Security Intelligence Assistant

## Problem

Security teams need to process large amounts of technical information and identify business impact.

## Solution

AI assistant that converts external information into actionable intelligence.

Pipeline:

Sources -> Extraction -> Classification -> Impact assessment -> Recommendations

## MVP

- News/RSS ingestion
- Summarization
- Entity extraction
- Risk scoring
- Daily digest generation
